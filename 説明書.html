🖼️ スクショ窓口 説明書

インストールがまだの人は、先に「はじめにお読みください_スタートアップガイド.html」をどうぞ。

できること

  • ⌘+Shift+3 / ⌘+Shift+4 で撮ったスクショが自動で「窓口」に集約される
  • メニューバーの 🖼️ アイコン or Dockのアイコンクリックで一覧の開閉
  • サムネにマウスを乗せると原寸プレビュー
  • サムネをドラッグして他のアプリにドロップで送れる（Discord / Slack / メール / Finder 等）
  • Cmd+クリックで複数選択 → ドラッグで一括送信、× で一括削除
  • 「🗑 窓口を全部ゴミ箱に送る」ボタンで全クリア（確認あり・ゴミ箱から復元可能）
  • サムネをダブルクリックで macOS Quick Look の全画面プレビュー
  • 検索ボックスでファイル名・日付の絞り込み
  • データはすべてローカル（クラウド送信なし）

AIエージェント連携（任意）

Claude Code などのAIエージェントに「さっきのスクショ見て」と言うだけで、AIが自分で最新スクショを見つけて開けるようになるコマンド3点セットを同梱しています。

コマンドひとこと使いどころ
lastshot窓口の最新スクショのパスを出す「さっきのスクショ見て」
selfshotAIが自分で画面を撮る「今の画面見て」（--win で前面ウィンドウのみ）
lastdlダウンロードの最新ファイルのパスを出す「今落としたやつ見て」

インストール

ターミナルを開いて、解凍したフォルダ内で：

bash エージェント連携/install.sh

これで ①3コマンドが ~/bin/ に入る ②ターミナル用のPATH設定 ③（y を選ぶと）Claude Code 用の説明が ~/.claude/CLAUDE.md に追記され、以後AIが「さっきのスクショ」等の言葉を自動でこのコマンドで解決します。

手動で設定したい場合は エージェント連携/CLAUDE_SNIPPET.md の中身を ~/.claude/CLAUDE.md に貼り付けてください。

  • 出力形式は「パス TAB 経過時間」（例: /Users/you/Pictures/スクショ窓口/xxx.png　30分前）
  • ⚠ selfshot --win（ウィンドウ単位の撮影）のみ Python の pyobjc が必要（pip3 install pyobjc）。全画面の selfshot と lastshot / lastdl は追加インストールなしで動きます
  • ⚠ selfshot の初回実行時、macOSが「画面収録」の権限を求めることがあります → システム設定 → プライバシーとセキュリティ → 画面収録 で許可

ホットキー（任意）

好きなキーで窓口を開閉したい場合は、BetterTouchTool や Karabiner-Elements などで、お好みのキーに次のシェルコマンドを割り当てます：

touch "$HOME/Library/Caches/スクショ窓口/.toggle_request"

何が変更されるか（透明性）

項目変更前変更後
スクショの保存先デスクトップ~/Pictures/スクショ窓口/
撮影直後の純正プレビュー表示する表示しない（即ファイル保存）

この2つを macOS の defaults write で変更するだけです。ほかにシステムへ勝手にインストールされるものはありません。いつでもメニューの「アンインストール」で元に戻せます。

アンインストール

  1. メニューバー 🖼️ → 「アンインストール（macOS設定を戻す）」 → 「実行」
    （保存先がデスクトップに戻り、純正プレビューが復活し、アプリが終了します）
  2. /Applications/スクショ窓口.app をゴミ箱へドラッグ

完全に消したい場合は次のフォルダも削除：

  • ~/Pictures/スクショ窓口/（過去のスクショ）
  • ~/Library/Caches/スクショ窓口/（サムネキャッシュ）
  • ~/Library/Application Support/スクショ窓口/（インデックス）

AIエージェント連携も入れていた場合は ~/bin/lastshot ~/bin/selfshot ~/bin/lastdl を削除してください。

トラブルシューティング

Q1. 「開発元が未確認」で起動できない
A. /Applications/スクショ窓口.app を右クリック →「開く」で初回起動してください。それでも開かない場合：システム設定 → プライバシーとセキュリティ → 「このまま開く」。
Q2. 撮影しても窓口に入らない
A. メニューの「保存先設定を確認」→ ~/Pictures/スクショ窓口/ と一致しているか確認。ずれていればアプリを再起動すると自動修正されます。直らない場合はターミナルで： 
defaults write com.apple.screencapture location ~/Pictures/スクショ窓口
killall SystemUIServer
Q3. 窓口が表示されない
A. メニューバー 🖼️ → 「窓口を開く」 / Dockアイコンクリック。それでも出なければメニュー → 「終了」→ 再起動。
Q4. 削除したくないのに撮ったスクショが消えた
A. 削除はゴミ箱に送るだけです。Finder のゴミ箱から復元できます。
Q5. macOS の元のスクショ動作（デスクトップ保存）に戻したい
A. メニュー → 「アンインストール（macOS設定を戻す）」を実行。
Q6. 二重起動の警告が出る
A. 正常動作です（1つだけ起動するよう制御しています）。古いプロセスが残っている場合はターミナルで： 
pkill -f "スクショ窓口"
rm -f ~/Library/Caches/スクショ窓口/.pid
Q7. アプリがクラッシュする
A. ログ ~/bin/screenshot_window.log を確認し、配布元に送ってください。

動作環境

  • macOS 13 (Ventura) 以降推奨（macOS 25 / Tahoe で開発）
  • Apple Silicon / Intel 両対応
  • ストレージ：アプリ本体 約73MB、サムネキャッシュ 約1MB / 100枚
  • 必要権限：なし（フォルダ書き込みは ~/Pictures, ~/Library 内のみ）
