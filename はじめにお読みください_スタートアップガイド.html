🖼️ スクショ窓口 スタートアップガイド

撮ったスクリーンショットが1か所に集まり、サムネから他のアプリへドラッグで送れるアプリです。
最初にやるのは次の3ステップだけ（約2分）。

💡 Claude Code を使っている人は、下の手順すら不要です。
同梱の Claude Codeにこのファイルを読ませてください.md を Claude Code に読ませれば、 インストールからAI連携まで全部AIがやってくれます（あなたが押すのはダイアログのボタン1個だけ）。

1アプリを「アプリケーション」フォルダへ

解凍したフォルダの中の スクショ窓口.app を、Finderの「アプリケーション」フォルダにドラッグします。

2初回だけ「右クリック → 開く」で起動

アプリケーションフォルダの スクショ窓口.app を 右クリック（2本指クリック）→「開く」。

⚠ 「開発元が未確認のアプリ」という警告が出ますが、「開く」を選べばOKです。
ダブルクリックだと警告が出るだけで開きません。初回だけ必ず右クリック→開くで。
2回目からはダブルクリック・Dock・Spotlightのどれでも起動できます。

3最初のダイアログで「設定する」を押す

起動すると「スクショの保存先を ~/Pictures/スクショ窓口/ に変更します」という確認が出ます。「設定する」を押すと準備完了。

あとは普段どおり ⌘ + Shift + 4（範囲）や ⌘ + Shift + 3（全画面）でスクショを撮るだけで、自動で窓口に集まります。メニューバーの 🖼️ アイコンか、Dockのアイコンをクリックすると一覧が開きます。

設定はいつでも、メニューバー 🖼️ →「アンインストール（macOS設定を戻す）」で元に戻せます。

＋AIと連携する 任意・Claude Code等を使っている人向け

AIエージェントに「さっきのスクショ見て」「今の画面見て」と言うだけで、AIが自分でスクショを見つけて開けるようになります。ターミナルを開いて、解凍したフォルダの中で：

bash エージェント連携/install.sh

質問に y と答えると、AI用の設定まで自動で入ります。詳しくは「説明書」のAIエージェント連携の章へ。

困ったときは同じフォルダの 「説明書.html」 のトラブルシューティングを見てください。
