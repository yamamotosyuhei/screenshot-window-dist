## スクショ・画面・ダウンロードの指示語は、エージェントが自分で解決する
ユーザーが「さっきのスクショ」「今の画面見て」「今落としたやつ」等と言ったら、
貼り付けやパスを待たず、以下のコマンドで自分で取得して Read で開いて見る。
出力はすべて「パス TAB 経過時間」形式（selfshotはパスのみ）。

- 「さっきのスクショ／今撮ったスクショ」→ `~/bin/lastshot`（`-n 3` で直近3枚）。保存先は `~/Pictures/スクショ窓口/`
- 「今の画面見て」→ `~/bin/selfshot`（エージェントが自分で全画面を撮る）／「今のウィンドウ見て」→ `~/bin/selfshot --win`（前面ウィンドウのみ。`--win Safari` でアプリ指定可）
- 「今落としたやつ／さっきダウンロードしたファイル」→ `~/bin/lastdl`（`-n 5` で直近5件。途中ファイルは除外）
- ⚠ lastshot/lastdl は経過時間が長い（目安10分超）時は「最新でも○分前のものですが合ってますか」と一言確認してから使う
- ⚠ 撮る・見るだけの操作なので確認プロンプト不要で実行してよい
